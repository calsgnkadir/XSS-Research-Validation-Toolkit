# 24 Ekim 2026 — ölçülmüş textarea bağlamı

Amaç: payload sayısını artırmak yerine mevcut probe ailesinin kaçırdığı tek
HTML parser bağlamını ölçmek ve dar bir eklemeyle karşılamak.

Üç native uzman durum belgeleri, bağımsız corpus/oracle ve uygulama alanlarında
ayrı dosyalarda çalıştı. Koordinatör diff ve oracle'ları inceledi. Önce mevcut
50 ailenin base + 18 mutation çıktıları native Chromium parser ile textarea
içinde sınandı: 950 denemeden hiçbiri marker öğesi üretmedi. Eski textarea
açma probunda kapanış etiketinden önceki marker metin olarak kalıyordu.

Yeni inert kapanış probu textarea dışında bir marker öğesi oluşturdu; escaped,
body, title ve eski textarea-opening kontrolleri sıfır kaldı. Önce bağımsız
browser koşusu 1 failed / 5 passed verdi; düzeltme sonrası sekiz dosyalık
birleşik kabul 381 passed, sıfır failure/error/skip oldu. Test süresi veya test
sayısı geliştirme saati ya da ürün doğruluk oranı olarak kullanılmadı.

Öğrenilen: yanıt içinde ham marker bulunması, HTML parser'ın onu element
olarak yorumlamasından farklıdır. Element oluşması da JavaScript execution
veya güvenlik açığı değildir. Bu nedenle HTTP kanıt seviyesi reflection kaldı.
Bağımsız oracle zorunlu browser CI seçimine eklendi; yeni uzak koşunun sonucu
yerel kabulden ayrı izlenir. A05 kullanıcı testi çalıştırılmadı.

# R3 browser zinciri — 6 Ekim 2026

Amaç: R2 HTTP oturumunu browser'da kontrol ederek stored gönderimi gerçek
JavaScript canary gözlemine bağlamak. Yeni dxaprove komutu ve kendini kapatan
yerel authenticated fixture oluşturuldu. Cookie ve bearer aktarımı, yanlış
rolde durma, iframe/gecikme, escape/JSON/dialog ve JS kapalı negatifleri test edildi.
R3 odaklı Chrome koşusu 21/21 geçti; direct-eval lexical scope, SPA route budget
ve allowlist edilmiş CSRF header aktarımı da kabul edildi.

Hata/öğrenme: javascript href ataması string döndürürse browser belgeyi
değiştirebiliyor. İlk href testi canary değerini kaybetti; void ile dönüş
değeri engellendi. Test gerçek tıklamayı kullanıyor. Observer hook eklememek
direct eval lexical scope'unu korudu. WebSocket filtreleme denemesi Playwright
context kapanışında kilitlendiği için kabul paketinden çıkarıldı; WebSocket/genel
ağ sandboxı bu komutun scope'u dışında.

Kanıt ayrı browser-proof/1 kayıtlarında: execution gözlemi ile açıklık triage'ı
ayrı; aynı hesap/rol laboratuvarı yetki aşımı veya CVE kanıtı değil. Sonuçlar
[R3 kanıt paketinde](../audit/2026-10-06-r3-final/README.md). Uzak Linux CI sonucu
ve browser'dan otomatik header harvest ayrıca yürütülmelidir.
